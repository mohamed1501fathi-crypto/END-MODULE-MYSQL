# E-Commerce Customer Churn Analysis – MySQL

## 📌 Project Overview
This project focuses on analyzing customer churn in an e-commerce dataset using MySQL.

The project includes data cleaning, data transformation, customer analysis, and customer return analysis.

## 🛠️ Tools Used
- MySQL
- SQL

## 📊 Project Tasks
- Handled missing values using Mean and Mode
- Removed outliers from the dataset
- Standardized inconsistent values
- Renamed and created columns
- Created Churn Status and Complaint Received columns
- Performed customer churn analysis using SQL queries
- Used filtering, aggregation, grouping, subqueries and CASE statements
- Created a `customer_returns` table
- Used JOIN to combine customer and return details

## 📈 Key Analysis
The project analyzed:
- Churned and active customers
- Customer tenure and cashback
- Customer complaints
- Preferred payment and order categories
- City tiers and customer distribution
- Customer satisfaction
- Coupon usage
- Order and transaction patterns
- Warehouse-to-home distance
- Customer return details
